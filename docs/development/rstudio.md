[RStudio Desktop](https://posit.co/downloads/) is an IDE for R. It combines a script editor, R console, plots, and project tools. Install [R](../languages/r.md) first; RStudio uses that separate R installation.

## Installation

Check that R is available:

```sh
R --version
```

Download **RStudio Desktop for macOS** from [Posit](https://docs.posit.co/ide/user/#direct-downloads-open-source). Open the downloaded disk image, drag **RStudio** to Applications, and launch it. Follow any setup prompts from the application.
