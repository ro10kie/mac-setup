[Sublime Text](https://www.sublimetext.com/) is a lightweight editor for code, configuration files, and notes.

## Installation

Install the [Homebrew cask](https://formulae.brew.sh/cask/sublime-text):

```sh
brew install --cask sublime-text
```

The cask installs the `subl` command. Open a new terminal and check it:

```sh
subl --version
```
