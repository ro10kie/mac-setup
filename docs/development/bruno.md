[Bruno](https://www.usebruno.com/) is an API client for exploring and testing HTTP services. Its collections live as text files in a directory, so they can be kept beside project code and reviewed with Git.

## Installation

Install the [Homebrew cask](https://formulae.brew.sh/cask/bruno):

```sh
brew install --cask bruno
```

Open **Bruno** from Applications to confirm that the app starts. The desktop app does not require the separate Bruno CLI for interactive requests.
