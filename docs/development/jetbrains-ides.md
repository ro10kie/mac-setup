[JetBrains IDEs](https://www.jetbrains.com/products/) combine code navigation,
refactoring, inspections, debugging, and project tools. For larger projects,
a full-featured IDE can make it easier to work across a substantial codebase.
These applications use more system resources than a lightweight editor, so
install only the IDEs that fit your work.

| IDE | Main focus |
| --- | --- |
| [IntelliJ IDEA](https://www.jetbrains.com/idea/) | Java and Kotlin development. |
| [PyCharm](https://www.jetbrains.com/pycharm/) | Python development. |
| [GoLand](https://www.jetbrains.com/go/) | Go development. |
| [CLion](https://www.jetbrains.com/clion/) | C and C++ development. |
| [WebStorm](https://www.jetbrains.com/webstorm/) | JavaScript and TypeScript development. |

## Installation

Choose the IDEs you need. The following Homebrew casks install each
application separately; you do not need to install all five.

### IntelliJ IDEA

Install the [IntelliJ IDEA cask](https://formulae.brew.sh/cask/intellij-idea)
for Java and Kotlin projects:

```sh
brew install --cask intellij-idea
```

### PyCharm

Install the [PyCharm cask](https://formulae.brew.sh/cask/pycharm) for Python
projects:

```sh
brew install --cask pycharm
```

### GoLand

Install the [GoLand cask](https://formulae.brew.sh/cask/goland) for Go
projects:

```sh
brew install --cask goland
```

### CLion

Install the [CLion cask](https://formulae.brew.sh/cask/clion) for C and C++
projects:

```sh
brew install --cask clion
```

### WebStorm

Install the [WebStorm cask](https://formulae.brew.sh/cask/webstorm) for
JavaScript and TypeScript projects:

```sh
brew install --cask webstorm
```

Open each installed IDE from Applications and complete its initial setup.
Check the [JetBrains licensing options](https://www.jetbrains.com/store/) for
the IDE and features you intend to use.
